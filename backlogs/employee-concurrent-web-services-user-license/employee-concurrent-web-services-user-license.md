# 従業員の「同時使用のWebサービス・ユーザー」はSuiteCloud Plusライセンスで別枠カウントされる

## 概要

対象前提：NetSuiteのライセンス管理・従業員設定に関わる方

従業員レコードの「アクセス」サブタブにある
「同時使用のWebサービス・ユーザー（Concurrent Web Services User）」チェックボックスは、
フル・ライセンス・ユーザーとは別に、**SuiteCloud Plusライセンスの枠でカウント**されます。

## 発覚のきっかけ

クライアントから「アカウントのユーザー数は上限に達していないはずなのに、
上限オーバーのエラーが出る」という問い合わせがあり、調査したところ判明しました。

普段のライセンス確認では、フル・ライセンス・ユーザーの人数を見て「まだ枠に余裕がある」と判断しがちですが、
この「同時使用のWebサービス・ユーザー」だけは独立した項目としてカウントされているため、
フル・ライセンス側の枠に余裕があってもSuiteCloud Plus側の上限に引っかかるケースがあります。

---

## 対処

このチェックボックスは、対象の従業員が実際にWebサービス（SuiteTalk/REST等）経由で同時アクセスする必要がない限り、
有効化する必要はありません。
使用しない従業員については、このチェックボックスを外してください。
